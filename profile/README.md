## .about

this is the home place of the ANORRL (ANOtherRobloxRetakeLol) project, a project aiming to provide a viable alternative creative outlet for Roblox.

we are constantly trying to innovate the client and site as to make sure everything is just right!

created by [kuro](https://github.com/2BEHDAMNED)

## .usage/contributing

if you would like to contribute feel free to make a pull request! we'll take a look make notes and pull the changes in (if it works of course LOL)

about the usage of our sources, we would like to have credit where possible (viewable to whoever will see your version of our project)

it's mostly just one developer (kuro) working on this project so help is appreciated.
